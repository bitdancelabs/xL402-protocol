# xL402-protocol

xL402 Gateway is a Lightning-native HTTP micropayment gateway that follows the x402-V2 HTTP transport specification. It uses standard HTTP status codes and headers (notably `402 Payment Required`) to provide seamless Lightning micropayment metering, billing, and cryptographic proof validation for any HTTP API.
